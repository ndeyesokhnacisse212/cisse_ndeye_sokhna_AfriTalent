# AfriTalent 
Projet fil rouge — Plateforme de mise en relation entre freelances africains et 
clients. 
- Auteur : Ndeye Sokhna Cisse
- Promotion : L1 IAGE — ISI
AfriTalent est une plateforme web moderne conçue pour connecter les meilleurs talent africains
Lien du site:https://ndeyesokhnacisse212.github.io/cisse_ndeye_sokhna_AfriTalent/

# Fonctionnalités du projet
le site est composé de 5 pages principales interconnectées:
- Accueil(`index.html`):Presentation de la plateforme
- Freelances(`Freelance.html`):mis en avant des profils et compétences disponibles
- Tarifs(`Tarifs.html`):grille tarifiare claire pour les recruteurs 
- Contact(`Contact.html`): formulaire pour joindre l'equipe
- About(`About.html`):vision, mission, et chiffre clés d'Afritalent

# Technologies utilisées
- HTML: structuration sémantique de l'ensemble des pages
- CSS: Design moderne, gestion des couleurs de la charte graphique et typographies
- Javascript: fonctionnalite
